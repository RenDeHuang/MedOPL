# OPL v20.3 更新日志

日期：2026-05-03
目标镜像 tag：`opl-v20.3`

## 本轮目标

v20.3 聚焦商业化硬化，不新增营销功能。目标是关闭 v20.2 暴露的 P0：Portal schema/状态写入死锁风险、账务不一致、OPL 文件任务 502 不可诊断、跨站连通和页面真实渲染缺证据。

## 本轮已开发

### 1. Portal schema migration 隔离

- 新增 `services/portal/src/state/portal-schema-migrator.mjs`。
- 新增 `services/portal/src/state/portal-schema-health.mjs`。
- 新增 `services/portal/src/migrate-schema.mjs`。
- 新增 `npm --prefix services/portal run migrate:schema`。
- `postgres_redis` 运行期不再在 `initializeStorageInfra()` 内执行 DDL，只校验 `schema_versions` 和必需表。

### 2. 账务事务 API

- 新增 `services/portal/src/state/portal-accounting-store.mjs`。
- 管理员充值优先走 `writeDb.topupWallet()`。
- `topupWallet/chargeWallet/refundWallet/makeupChargeWallet` 统一用单事务写 `wallets + ledger_entries + audit_events`。
- ledger 插入显式包含 `run_id/workspace_id/order_id/source_id` 等真实 Postgres 非空字段。
- 同一个 `idempotencyKey` 重放不会重复改余额、写 ledger 或写 audit。

### 3. Workspace 领域 store 与安全路由切换

- 新增 `services/portal/src/state/portal-workspace-store.mjs`。
- 新增 `services/portal/src/state/portal-resource-order-store.mjs`。
- 新增 `services/portal/src/state/portal-lab-billing-store.mjs`。
- `workspace-storage.routes.mjs` 的 storage order 和 signed upload 在 `postgres_redis` 模式下使用 workspace store 增量 upsert。
- JSON 模式仍走原兼容写入，避免误跳过完整落盘。
- resource order 和 lab package 真实路由尚未切换，原因是它们和冻结、wallet、ledger、事件写入强耦合，不能半切。

### 4. OPL run 错误契约和 runner preflight

- 新增 `services/opl-runtime-bridge/src/run-contract.mjs`。
- 新增 `services/opl-runtime-bridge/src/run-error-mapper.mjs`。
- 新增 `services/opl-runtime-bridge/src/run-observability.mjs`。
- `runner-client` 保留 runner 结构化错误，不再压平成字符串。
- `runtime-bridge-routes` 失败响应返回 `{ ok:false, error:{ code, stage, message, retryable, details, correlationId } }`。
- 新增 `adapters/med-autoscience-runner/src/runner-k8s-preflight.mjs`。
- 新增 `adapters/med-autoscience-runner/src/runner-k8s-errors.mjs`。
- runner 在真实 apply 前做 namespace、RBAC、server-side dry-run 检查。
- 错误码对齐 v20.3 稳定集合：`RUNNER_NAMESPACE_NOT_FOUND`、`RUNNER_K8S_RBAC_DENIED`、`RUNNER_MANIFEST_INVALID`、`RUNNER_K8S_APPLY_FAILED` 等。

### 5. 连通性、渲染、证据链 gate

- 新增 `scripts/smoke-test-v20.3-connectivity-matrix-contract.mjs`，要求 13 条 P0 连接边。
- 新增 `scripts/live-test-v20.3-connectivity-matrix.mjs`，输出 `edge/ok/status/latencyMs/buildTag/module/source/correlationId`。
- 新增 `scripts/live-test-v20.3-portal-rendering.mjs`。
- 新增 `scripts/live-test-v20.3-session-trace-connectivity.mjs`。
- 当前 rendering/session-trace 脚本仍偏证据结构，尚未完成主动浏览器和主动 API 操作，不能替代 live 终验。

### 6. 可恢复 live gate 与 T+1 exact gate

- 新增 `scripts/live-test-v20.3-same-day-e2e.mjs`，支持 `--stage all` 和单阶段恢复。
- 新增 `scripts/live-test-v20.3-opl-file-run.mjs`。
- 新增 `scripts/live-test-v20.3-resource-delete-stop-billing.mjs`。
- 新增 `scripts/live-test-v20.3-cos-exact-reconcile.mjs`。
- 未设置 `RUN_V20_3_LIVE` 时明确 skip，不会误触发 live。
- exact gate 强制 `COS_LIVE_BILL_OBJECT_KEY`，不允许 preview 冒充 exact。

### 7. 小白文案和商业就绪文档

- 新增 `scripts/smoke-test-v20.3-portal-copy-contract.mjs`。
- 用户侧页面禁止直出 `kubectl/RBAC/TKE/CVM/COS/OpenCost/502` 等底层词。
- 服务器与账单页面文案收敛为“云服务器、真实账单、待校准、最终扣费”等业务表达。
- 新增 `docs/reports/2026-05-03-OPL-v20.3-Commercial-Readiness-Checklist.md`。
- 新增 `docs/reports/2026-05-03-OPL-v20.3-Pending-Verification.md`。
