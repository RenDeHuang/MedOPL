## 本轮实际改动

- Portal 登录快路径：
  - `GET /login`、`GET /register` 不再先读完整用户快照。
  - `POST /login`、`POST /register` 无 session cookie 时使用 `auth_light`。
  - Portal store 新增 `readAuthDb()`，只读取认证所需 users/settings/sessions。
  - 登录成功优先使用 `writeDb.persistPortalSessions()`，只持久化 session，避免登录提交触发全库 snapshot。
- request body 错误处理：
  - 新增 `HttpBodyError` 和 `isHttpBodyError`。
  - `readBody()` 支持 `limitBytes`，超限返回 `request_body_too_large`，客户端断开返回 `request_body_aborted`。
- 账务事务：
  - `portal-accounting-store` 增加 orphan audit 扫描。
  - 管理员充值强制走 `writeDb.topupWallet()`，没有账务事务 store 时拒绝充值，不回退到旧的非原子路径。
- OPL run 错误契约：
  - run 成功响应补齐 `traceId` 和 `correlationId`。
  - runner 非 2xx 错误保留 `status/payload/correlationId`。
  - 用户可见错误 message 不暴露 `kubectl/RBAC/YAML`。
- 连通性和渲染 gate：
  - 新增 v20.31 连通性矩阵 contract 和 live gate。
  - 新增 Portal 模块 wiring contract 和浏览器渲染 gate。
  - 新增 Portal/OPL/Trace session-trace live gate，并修复登录后 cookie 传递。
- 文档：
  - 新增云端 gate 报告。
  - 新增继承矩阵。
