# OPL v20.34 Commercial Readiness Correction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 v20.33 工程可运行版本修正为 v20.34 商业化小白试运营候选版本，覆盖套餐、资源、工作空间、账单、轨迹、OPL traceId、admin 运营台和全量点击 gate。

**Architecture:** 采用“合同测试先行 + 页面职责收敛 + 后端应用服务编排 + 全量点击证据”的方式推进。前端只提交用户选择和展示状态，后端负责套餐/订单/资源的交易编排；Portal、OPL Gateway、Runtime Bridge、Admin payload 保持边界清晰，避免页面直接串多条内部链路。

**Tech Stack:** Node.js ESM, Vue 3, TypeScript, Vite, Portal service, OPL Web Gateway, OPL Runtime Bridge, Sentrux, Playwright/browser live scripts.
